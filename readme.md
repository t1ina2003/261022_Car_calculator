# 🚗 買車 vs 🚕 天天搭計程車｜台灣通勤成本計算器

在台灣，如果不買車、每天搭計程車上下班，要花多少錢？跟買車相比哪個划算？
本工具以互動圖表即時比較兩者的累積成本。

## 功能

- **累積成本折線圖**：逐月比較買車與計程車的累積花費，找出交叉點
- **年均成本結構**：拆解買車的折舊、油費、停車、稅金、保險、保養
- **距離敏感度**：1–40 km 不同單程距離下的年均成本
- **損益平衡距離**：單程超過多少公里，買車才划算
- **兩種計算模式**：折舊成本（期末賣車）/ 現金支出（不賣車）

## 計算假設

| 項目 | 預設值 / 公式 |
| --- | --- |
| 計程車費率 | 台北市：起跳 85 元（1.25 km），每 200 m 加 5 元，延滯每 60 秒 5 元 |
| 每日車資 | 單趟車資 × 2（來回） |
| 上班天數 | 248 天 / 年 |
| 車價 / 折舊 | 80 萬，定率遞減折舊每年 12% |
| 牌照稅 + 燃料費 | 依排氣量自動帶入（1201–1800cc：7,120 + 4,800） |
| 油費 | 通勤里程 ÷ 油耗 × 95 油價 |
| 停車 | 住家 4,000 + 公司 3,000 元 / 月 |

> ⚠️ 僅供參考：未計入夜間加成、叫車費、貸款利息、過路費、罰單及假日用車價值。
